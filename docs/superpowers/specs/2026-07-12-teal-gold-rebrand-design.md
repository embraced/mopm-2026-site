# MOPM 2026 — Teal/Gold Rebrand (Design Handoff Implementation)

**Date:** 2026-07-12
**Source:** `../mopm-2026/docs/design_handoff_mopm2026/` (Claude Design hi-fi handoff)
**Target:** this repo (`mopm-2026-site`, live at 2026.mopm.tw)

## Goal

Rebrand the existing live Astro site from its current royal-blue identity to the
handoff's **teal (`#58D5D0`) + gold (`#C9A86A`)** identity, adopting the handoff's
section structure. This is a **visual + structural rebrand only**. All content stays
data-driven (yaml + i18n); dark-mode toggle, `/en` pages, EventSchema, and the agenda
tooling pipeline are preserved.

## Principles

1. **Rebrand presentation, keep content data-driven.** The handoff's hardcoded 2026
   session titles are prototype sample data. The real agenda lives in `agenda.yaml`
   (regenerated by the sibling tooling repo). Never paste handoff session strings into code.
2. **No schema change.** Plenary "band" kind (keynote/feature/break) is derived from the
   existing `slot.category`; the neutral org chip is derived from `track.organizer`.
   `lib/agenda.ts` and the tooling repo's `agenda-types.ts` are untouched.
3. **Preserve bilingual + dark mode.** Every new string goes through i18n; a teal/gold
   dark palette is derived so the existing `ThemeToggle` keeps working.
